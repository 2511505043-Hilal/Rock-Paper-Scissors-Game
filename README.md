🪨 Rock 📄 Paper ✂️ Scissors Game
A feature-rich C# Console Application based on the classic Rock Paper Scissors game. The project includes multiple game 
modes, player management, statistics, achievements, match history, and automatic data saving.

✨ Features

  ▶️ Multiple game modes (Single Match, Best of 3, Best of 5, Best of 10, Endless)
  👥 Create, load, rename, and delete player profiles
  📊 Detailed player statistics and win rate
  🏆 Achievement system with progress tracking
  📁 Match history with pagination
  💾 Automatic save and load functionality
  ✅ Input validation and user-friendly console interface
  
🛠 Technologies

  C#
  .NET
  LINQ
  File I/O
  Collections (List, Dictionary)

🚀 Getting Started

  1.Clone the repository.
  2.Open the solution in Visual Studio.
  3.Run the project.
